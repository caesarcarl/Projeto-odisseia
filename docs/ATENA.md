# Atena IA no ecossistema Odisseia

A Atena é a camada de IA educacional e de conhecimento do Odisseia.

Repositório principal:
https://github.com/caesarcarl/Atena-IA

## Papel

A Atena foi concebida para combinar assistência de IA com aprendizagem ativa. O método socrático é parte da identidade: perguntas e explicações devem ajudar o estudante a construir o raciocínio.

## Integração conceitual

```text
Odisseia OS / Cyberdeck
          │
          ├── terminal e ferramentas
          ├── conhecimento local
          ├── modelos locais/híbridos
          └── Atena Core
                  │
                  ▼
            interface Atena
```

A Atena deve permanecer em repositório próprio quando isso facilitar versionamento e desenvolvimento. O repositório Odisseia aponta para ela como um dos pilares do ecossistema.
